C-BASEサイト一式

このフォルダには、公開中のサイトから復元したHTML・CSS・JavaScriptと、
Googleフォームへ送信できる専用デザインのお問い合わせフォームが入っています。

ファイル構成
- index.html: ページ本体
- styles.css: デザイン
- script.js: メニュー、アニメーション、フォーム送信
- assets/images/: 写真を入れる場所

写真について
受け取った9枚をWeb向けに軽量化し、次の場所へ組み込み済みです。

- hero.jpg: ヒーロー背景
- tour-sangenzan.jpg: 三原山ツアー
- tour-urasabaku.jpg: 三原山・裏砂漠ツアー
- guide.jpg: ガイド紹介
- tour-arrange.jpg: アレンジツアー
- tour-group.jpg: 団体・学校・研修向け
- c-base-logo.jpg: C-BASE
- villa-limone.jpg: Villa Limone
- hotel-narumi.jpg: HOTEL Narumi

Vercelへ反映する方法
1. このフォルダを開く
2. ターミナルで vercel --prod を実行する
3. 既存の c-base プロジェクトを選ぶ

GitHubとVercelを連携している場合は、この一式をGitHubのリポジトリへ
アップロードするとVercelが自動で更新します。

フォームについて
画面はC-BASE専用デザインですが、回答先は現在のGoogleフォームです。
追加項目（送迎、お子様、体力面など）はGoogleフォームの「メッセージ」欄へ
まとめて保存されます。
